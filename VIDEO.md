# 2-minute demo video: record it now

## Setup (2 min)
1. In Chrome, open these 3 tabs **in this order** (Cmd+Shift+R each to force-reload):
   - Tab 1: http://localhost:8077/story
   - Tab 2: http://localhost:8077/  (then type **Builder.ai** and click **Run**: it replays from cache in about 2 s)
   - Tab 3: http://localhost:8077/compare
2. Hide the bookmarks bar (Cmd+Shift+B), go full screen, mute notifications.
3. Press **Cmd+Shift+5** → Record Entire Screen → Options → Microphone: MacBook Microphone → Record.
4. Stop with ⏹ in the menu bar → trim in QuickTime → upload to YouTube as **Unlisted**.
