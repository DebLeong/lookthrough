## Setup (2 min)
1. In Chrome, open these 3 tabs **in this order**:
   - Tab 1: http://localhost:8077/story
   - Tab 2: http://localhost:8077/?replay=manus-ai-asof-2025-12-29-70460b&speed=6
   - Tab 3: http://localhost:8077/compare
2. Press Cmd+Shift+F to hide the bookmarks bar, and put Chrome in full screen (Ctrl+Cmd+F). Close Slack, mute notifications.
3. Press **Cmd+Shift+5** → "Record Entire Screen" → Options → Microphone: **MacBook Microphone** → Record.
4. Stop with the ⏹ button in the menu bar. Trim the start and end in QuickTime (Edit → Trim).
5. YouTube → Create → Upload → Visibility **Unlisted** → paste the link into Devpost.
